What do these result codes mean?
  • Claim Fully Supported — the cited source clearly states the claim.
  • Claim Partly Supported — the source backs the gist, but the claim adds specifics the source doesn't fully support.
  • Claim Not Supported — the cited source does not contain the claim.
  • Contradicted — the cited source states the opposite of the claim.
  • Citations Identify Existing / Non-Existent Articles — whether each cited reference could be located at all.
  • Inaccessible Articles — a citation is present, but the source could not be retrieved (paywall, dead link, or unreadable), so the claim could not be checked.
  • No Citation Provided — the claim carries no inline citation.
  • Uncited Claim — Supporting Source Found / Partial — an uncited claim was matched to a supporting source via backup search.
  • Uncited Claim — No Supporting Source Found — backup search found no source for an uncited claim.
